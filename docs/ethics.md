# Ethics & Legal

RedScout is built on three non-negotiable rules:

1. **Authorization only.** Every scan requires a signed scope file.
2. **Minimum necessary action.** No weaponized exploits by default.
3. **Audit everything.** Every action is hash-chained and logged.

## Obtaining Authorization

Before running a scan, ensure you have:
- A written agreement with the target owner
- A clearly defined scope (IPs, domains, time window)
- An emergency contact

## Unauthorized Use

Running RedScout against systems you don't own without written permission
is illegal in most jurisdictions and will result in:
- Immediate repository ban
- Potential criminal prosecution

We do not support, condone, or assist unauthorized testing.
